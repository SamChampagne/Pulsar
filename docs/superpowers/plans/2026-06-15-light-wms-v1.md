# Light WMS v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Light WMS business module — inventory (stock per item × bin) moved through the full warehouse loop (receiving → putaway → picking), standalone (no TMS coupling) in v1.

**Architecture:** A new gated business module `apps/api/src/modules/wms`. Stock truth is an append-only `StockMovement` ledger; the current balance `InventoryLevel` is maintained in the SAME transaction as every movement (never mutated alone). Document statuses (`Receipt`, `PickOrder`) go through pure state machines in `@pulsar/shared/wms`. The warehouse reuses the existing `Location` (type `WAREHOUSE`). Web adds a "Warehouse" nav group with a dashboard, an inventory browser, and receiving/picking workbenches.

**Tech Stack:** NestJS + Prisma (`@pulsar/database`), `@pulsar/shared` (pure, vitest), SvelteKit 5 runes (ssr=false), jest e2e in `apps/api/test`.

**Template to mirror (freshly built, analogous):** the **Fleet module** — `apps/api/src/modules/fleet/**`, `packages/shared/src/fleet/**`, `apps/web/src/routes/(app)/fleet/**`. Copy its patterns for DTOs (`@IsDate()` on date fields!), controllers (decorator import paths), module wiring (global `PrismaModule` exports `PrismaService`+`OwnershipService`; import `AuditLogsModule`), e2e bootstrap, and web pages.

**Infra notes (Windows):**
- Run API as detached `node dist/main.js`; after any API rebuild, kill the port-3000 process and restart. NEVER run `pnpm --filter @pulsar/api build` while `pnpm dev` (nest watch) runs.
- After a Prisma migration, the detached API holds the client DLL lock → kill it before `pnpm db:generate`.
- `GET /transportation/*` and list endpoints cap `pageSize` at 100.
- After changing `packages/shared` or `packages/database`, rebuild them (`pnpm --filter @pulsar/shared build`, `pnpm --filter @pulsar/database build`).

```ts
export enum StockMovementType {
  RECEIPT = 'RECEIPT',
  MOVE = 'MOVE',
  PICK = 'PICK',
  ADJUSTMENT = 'ADJUSTMENT',
}

export enum BinKind {
  RECEIVING = 'RECEIVING',
  STORAGE = 'STORAGE',
  SHIPPING = 'SHIPPING',
}

export enum ReceiptStatus {
  DRAFT = 'DRAFT',
  POSTED = 'POSTED',
  CANCELLED = 'CANCELLED',
}

export enum PickOrderStatus {
  OPEN = 'OPEN',
  PICKED = 'PICKED',
  COMPLETED = 'COMPLETED',
  CANCELLED = 'CANCELLED',
}

const RECEIPT_TRANSITIONS: Record<ReceiptStatus, ReceiptStatus[]> = {
  [ReceiptStatus.DRAFT]: [ReceiptStatus.POSTED, ReceiptStatus.CANCELLED],
  [ReceiptStatus.POSTED]: [],
  [ReceiptStatus.CANCELLED]: [],
};

export function canTransitionReceipt(from: ReceiptStatus, to: ReceiptStatus): boolean {
  if (from === to) return true;
  return RECEIPT_TRANSITIONS[from]?.includes(to) ?? false;
}

const PICK_TRANSITIONS: Record<PickOrderStatus, PickOrderStatus[]> = {
  [PickOrderStatus.OPEN]: [PickOrderStatus.PICKED, PickOrderStatus.COMPLETED, PickOrderStatus.CANCELLED],
  [PickOrderStatus.PICKED]: [PickOrderStatus.COMPLETED, PickOrderStatus.CANCELLED],
  [PickOrderStatus.COMPLETED]: [],
  [PickOrderStatus.CANCELLED]: [],
};

export function canTransitionPickOrder(from: PickOrderStatus, to: PickOrderStatus): boolean {
  if (from === to) return true;
  return PICK_TRANSITIONS[from]?.includes(to) ?? false;
}

export type BalanceResult = { ok: true; next: number } | { ok: false; reason: 'NEGATIVE' };

export function applyToBalance(current: number, delta: number, opts?: { allowNegative?: boolean }): BalanceResult {
  const next = current + delta;
  if (next < 0 && !opts?.allowNegative) return { ok: false, reason: 'NEGATIVE' };
  return { ok: true, next };
}
```

// helper: read a level qty (0 if absent) within a tx client
private async readQty(tx: any, tenantId: string, itemId: string, binId: string): Promise<number> {
  const lvl = await tx.inventoryLevel.findFirst({ where: { tenantId, itemId, binId } });
  return lvl ? Number(lvl.qtyOnHand) : 0;
}

// helper: set a level to an absolute qty (upsert), within a tx client
private async setQty(tx: any, tenantId: string, itemId: string, binId: string, qty: number) {
  await tx.inventoryLevel.upsert({
    where: { tenantId_itemId_binId: { tenantId, itemId, binId } },
    create: { tenantId, itemId, binId, qtyOnHand: qty },
    update: { qtyOnHand: qty },
  });
}

// THE single ledger-writing primitive. Call inside a $transaction.
// delta is applied to the (itemId, binId) balance; writes one StockMovement.
async postMovement(
  tx: any,
  args: { tenantId: string; userId?: string; type: StockMovementType; itemId: string; fromBinId?: string; toBinId?: string; qty: number; refType?: string; refId?: string; note?: string },
) {
  // decrement fromBin (availability-checked), increment toBin
  if (args.fromBinId) {
    const cur = await this.readQty(tx, args.tenantId, args.itemId, args.fromBinId);
    const res = applyToBalance(cur, -args.qty);
    if (!res.ok) throw new ConflictException('Insufficient stock in source bin');
    await this.setQty(tx, args.tenantId, args.itemId, args.fromBinId, res.next);
  }
  if (args.toBinId) {
    const cur = await this.readQty(tx, args.tenantId, args.itemId, args.toBinId);
    await this.setQty(tx, args.tenantId, args.itemId, args.toBinId, cur + args.qty);
  }
  await tx.stockMovement.create({
    data: {
      tenantId: args.tenantId, type: args.type, itemId: args.itemId,
      fromBinId: args.fromBinId ?? null, toBinId: args.toBinId ?? null, qty: args.qty,
      refType: args.refType ?? null, refId: args.refId ?? null, note: args.note ?? null,
      createdById: args.userId ?? null,
    },
  });
}

async list(tenantId: string, query: InventoryListQueryDto) {
  const where: any = { tenantId };
  if (query.itemId) where.itemId = query.itemId;
  if (query.binId) where.binId = query.binId;
  if (query.locationId) where.bin = { locationId: query.locationId };
  return this.prisma.inventoryLevel.findMany({
    where,
    orderBy: [{ itemId: 'asc' }],
    take: 500,
    include: { item: { select: { id: true, sku: true, name: true, unit: true } }, bin: { select: { id: true, code: true, kind: true, locationId: true } } },
  });
}

async move(tenantId: string, userId: string, dto: MoveStockDto) {
  if (dto.fromBinId === dto.toBinId) throw new BadRequestException('Source and destination bins must differ');
  await this.prisma.$transaction(async (tx) => {
    await this.postMovement(tx, { tenantId, userId, type: StockMovementType.MOVE, itemId: dto.itemId, fromBinId: dto.fromBinId, toBinId: dto.toBinId, qty: dto.qty, note: dto.note });
  });
  await this.audit.log({ tenantId, userId, action: AuditAction.UPDATE, entityType: 'wms-inventory', entityId: dto.itemId, after: { move: dto } });
}

async adjust(tenantId: string, userId: string, dto: AdjustStockDto) {
  if (dto.qtyDelta === 0) throw new BadRequestException('qtyDelta must be non-zero');
  await this.prisma.$transaction(async (tx) => {
    const cur = await this.readQty(tx, tenantId, dto.itemId, dto.binId);
    const res = applyToBalance(cur, dto.qtyDelta); // refuses below zero (no override — even adjustments don't go negative)
    if (!res.ok) throw new ConflictException('Adjustment would drive the bin negative');
    await this.setQty(tx, tenantId, dto.itemId, dto.binId, res.next);
    await tx.stockMovement.create({
      data: { tenantId, type: StockMovementType.ADJUSTMENT, itemId: dto.itemId,
        fromBinId: dto.qtyDelta < 0 ? dto.binId : null, toBinId: dto.qtyDelta > 0 ? dto.binId : null,
        qty: Math.abs(dto.qtyDelta), note: dto.note ?? null, createdById: userId },
    });
  });
  await this.audit.log({ tenantId, userId, action: AuditAction.UPDATE, entityType: 'wms-inventory', entityId: dto.itemId, after: { adjust: dto } });
}

3. **Pick → stock decremented**: create pick order, add line (`fromBinId: storage, qty: 4`), complete → `GET /wms/inventory` → storage 6.
4. **Over-pick refused**: pick order with line qty 999 from storage → complete → expect 409.
5. **Adjust**: `POST /wms/inventory/adjust {itemId, binId: storage, qtyDelta: -2}` → storage 4; `qtyDelta: -999` → 409.
6. **Tenant isolation**: `GET /wms/items` returns the created item; (if a second tenant token exists in helpers, assert 404 cross-tenant; else skip with a comment — service is tenant-scoped by construction).
7. **Module gating**: skip-with-comment (covered structurally by `@RequireModule`) OR toggle+restore if the fleet suite does it cheaply.
